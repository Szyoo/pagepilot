# 消息协议

所有消息使用 JSON，并由 `src/schema` 中的 Zod 定义校验。

## 通道

- 首选 WebSocket，不可用时回退 SSE，再回退定时轮询。
- 请求头携带令牌：`Authorization: Bearer <token>`。
- 断线后指数退避重连；重连成功后后台先发送 `snapshot`，再增量推送。

## 上行（扩展 → 后台）

| kind        | 说明                                                           |
| ----------- | -------------------------------------------------------------- |
| `capture`   | 页面元素信息：标签、文本、属性、定位器；敏感字段只带类型不带值 |
| `recording` | 一次录制得到的步骤序列                                         |
| `runReport` | 规则执行结果：成功与否、失败步骤、错误信息                     |

## 下行（后台 → 扩展）

| kind         | 说明                                 |
| ------------ | ------------------------------------ |
| `snapshot`   | 全量规则，用于首次连接和重连校准     |
| `ruleUpsert` | 新增或更新一条规则，版本号更大才生效 |
| `ruleRemove` | 删除一条规则                         |

## 隐私约定

- 密码框、支付字段、验证码输入框不采集值。
- `profile` 与 `secret` 数据只存在本机，不出现在任何上行消息中。
